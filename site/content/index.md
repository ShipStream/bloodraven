#title
MySQL failover across sites, without the managed database bill.

#description
Bloodraven is a Kubernetes operator for MySQL async replication failover groups.
It owns promotion, DNS steering, fencing, clone bootstrap, and backups, so a
site-level outage recovers without a human.

Keep this table synchronized with your PrometheusRule package. Alert annotations should link to the matching page or heading. Use the [Observability Change Checklist](/docs/observability/observability-change-checklist) when adding, removing, or changing alerts, alert annotations, runbook links, dashboard links, or actionable Events.

## Alerts

| Alert | Primary runbook | First checks |
|---|---|---|
| `BloodravenOperatorDown` | [Operator unavailable](/docs/operations/runbooks#operator-unavailable) | Deployment, leader election, logs |
| `BloodravenNoWritableSite` | [Emergency manual promotion](/docs/operations/runbooks#emergency-manual-promotion) or [Total site loss](/docs/operations/runbooks#total-site-loss) | Active site, pod reachability, fencing |
| `BloodravenFailoverOccurred` | [Failover](/docs/operations/failover) | DNS, app writes, old primary state |
| `BloodravenDivergentTransactions` | [Divergent old primary recovery](/docs/operations/runbooks#divergent-old-primary-recovery) or [Divergent replica](/docs/operations/runbooks#divergent-replica) | Events (`DataLossDetected` / `DivergentReplicaDetected`), `status.sites[].divergenceDetectedBy`, GTIDs, old primary fenced |
| `BloodravenReplicationLagging` | [Replication lag high](/docs/operations/troubleshooting#replication-lag-high) | lag metric, MySQL replica status |
| `BloodravenReplicationDown` | [Replication lag high](/docs/operations/troubleshooting#replication-lag-high); sites awaiting a post-restore reclone are excluded by design ([Peer replication during a full-instance restore](/docs/backup-and-restore/backup-restore#peer-replication-during-a-full-instance-restore)) | `bloodraven_replication_running`, `bloodraven_restore_reclone_pending`, MySQL replica status |
| `BloodravenRestoreReclonesHeld` | [Peer reclones after a full-instance restore](/docs/backup-and-restore/backup-restore#peer-reclones-after-a-full-instance-restore) | `status.restoreReclones`, `status.restoreInPlace.message`, the primary's data before choosing what to keep |
| `BloodravenBackupStale` | [Failed backup](/docs/operations/runbooks#failed-backup) | latest `MysqlBackup`, Job logs |
| `BloodravenBackupArtifactCleanupFailing` (`increase(bloodraven_backup_artifact_cleanup_failures_total[6h]) > 0`) | [Artifact cleanup](/docs/backup-and-restore/backup-restore#artifact-cleanup) | `ArtifactCleanup` condition on Terminating `MysqlBackup`s, cleanup Job termination message, S3 credentials or claim |
| `BloodravenBackupVerificationStale` | [Backup Verification](/docs/backup-and-restore/backup-verification) | verification CRs, restore logs |
| `BloodravenPITRArchiveLagging` | [Backup And Restore](/docs/backup-and-restore/backup-restore) | archiver metrics, object storage, `PITRArchiveReady` reason and `status.pitr.archive` (an archive identity refusal stops uploads) |
| `BloodravenDNSUpdateFailed` | [DNS failover stuck](/docs/operations/runbooks#dns-failover-stuck) | `DNSEndpoint`, external-dns logs |
| `BloodravenSplitBrainDetected` | [Split-brain recovery](/docs/operations/runbooks#split-brain-recovery) | writable sites, app traffic, GTIDs |
| `BloodravenDragonflySiteDown` | [Dragonfly degraded](/docs/operations/runbooks#dragonfly-degraded) | `status.dragonfly.sites[]`, Dragonfly pods, active Service endpoints |
| `BloodravenDragonflyPromotionFailed` | [Dragonfly degraded](/docs/operations/runbooks#dragonfly-degraded) | planned-failover Dragonfly status, Events, Redis client impact |
| `BloodravenDragonflySessionsLost` | [Dragonfly degraded](/docs/operations/runbooks#dragonfly-degraded) | `status.dragonfly.replTakeoverSupported`, `DragonflySessionsLost` Events, image pin |
| `BloodravenDragonflyManagerPanic` | [Dragonfly degraded](/docs/operations/runbooks#dragonfly-degraded) | operator logs, panic counter, current `status.dragonfly` |
| `BloodravenKeyringNotSealed` | [Data-at-rest encryption](/docs/configuration/encryption-at-rest#status-and-monitoring) | `status.encryptionAtRest.sites[].phase` and `.message`, escrow Secret exists, sidecar `/keyring/status` |
| `BloodravenKeyringEscrowFailing` | [Data-at-rest encryption](/docs/configuration/encryption-at-rest#disaster-recovery) | `bloodraven_keyring_escrow_pushes_total{outcome="failure"}`, sidecar logs, operator `/keyring/escrow` rejections |
| `BloodravenUnencryptedTablespaces` | [Data-at-rest encryption](/docs/configuration/encryption-at-rest#coverage) | `bloodraven_encryption_unencrypted_tablespaces`, whether the group was adopted with partial coverage |
| `BloodravenLicenseUpdatesExpiring` | [Licensing](/docs/licensing) | `bloodraven_license_updates_expiry_timestamp_seconds`. Renewal reminder only — the operator does not gate or change behavior when the timestamp is in the past. |

## Kubernetes Events

| Event category | Expected operator action | Runbook |
|---|---|---|
| Planned failover requested/started/completed | Drain writes, promote target, update DNS | [Planned Failover](/docs/operations/planned-failover) |
| `PlannedFailoverFailed` with outcome `SourceLeftFenced` | Nothing was written to the target; the source stays read-only. The operator re-asserts an attributable fence on its own; some causes are manual | [Planned failover left the source fenced](/docs/operations/runbooks#planned-failover-left-the-source-fenced) |
| `PlannedFailoverPromotionConfirmationFailed` | Names the target as the last failover target without a cooldown; emergency failover may promote the fenced source | [Promoted but unconfirmed](/docs/operations/planned-failover#promoted-but-unconfirmed) |
| `PlannedFailoverManualRecoveryRequired` / `PlannedFailoverHoldPersisted` | Holds automatic failover for the group (`AutomaticFailoverHeld=True`) until a human acknowledges it. Page | [Planned failover automation hold](/docs/operations/runbooks#planned-failover-automation-hold) |
| `PlannedFailoverStalledManagerAbsent` / `PlannedFailoverStatusStalled` | No topology manager, or status writes failing, while a planned failover holds its claim; the run ends after 5 or 2 minutes (10 seconds once its promotion is recorded and published) | [Planned failover](/docs/operations/planned-failover#status-stalls-and-the-terminal-marker) |
| `PlannedFailoverDeferred` with `DeploymentHold` | Inspect blocking operation, instance, and `admission.retryTime`; prefer completion/release or expiry over interruption | [Deployment coordination](/docs/operations/operations#deployment-coordination) |
| `DeploymentLeaseRevoked` | Stop deployment heartbeat and further DDL; check `topologyGeneration`, revocation reason, and post-DDL recovery requirements | [Deployment coordination](/docs/operations/operations#deployment-coordination) |
| Emergency failover started/completed | Promote best candidate, taint old site, update DNS | [Failover](/docs/operations/failover) |
| Reclone started/completed/failed | Rebuild replica from active primary | [Divergent old primary recovery](/docs/operations/runbooks#divergent-old-primary-recovery) |
| Backup started/completed/failed | Create/update `MysqlBackup` Job and status | [Failed backup](/docs/operations/runbooks#failed-backup) |
| `ArtifactCleanupFailed` / `ArtifactCleanupBlocked` / `ArtifactCleanupNothingFound` | Retry or block artifact cleanup of a deleted `MysqlBackup`; the CR stays Terminating | [Artifact cleanup](/docs/backup-and-restore/backup-restore#artifact-cleanup) |
| `ArtifactCleanupProducerStuck` | Deleting an abandoned backup waits for its producing Job's pods to stop; one has not after 10 min. Once its node is confirmed down, force-delete the pod | [Artifact cleanup](/docs/backup-and-restore/backup-restore#artifact-cleanup) |
| `ArtifactCleanupDeferred` / `RetentionDeferred` | Keep a backup a verification is reading; informational unless it persists after the run ended | [Backup verification](/docs/backup-and-restore/backup-verification#the-backup-is-held-while-it-is-read) |
| Restore started/completed/failed | Gate bootstrap or restore workflow | [Failed restore](/docs/operations/runbooks#failed-restore) |
| Verification started/completed/failed | Restore backup into ephemeral MySQL | [Backup Verification](/docs/backup-and-restore/backup-verification) |
| `PITRArchiveNotReady` with an `Archive*` reason (`ArchiveLegacy`, `ArchiveForeign`, `ArchiveCopy`, `ArchiveDescriptorMissing`, `ArchiveEncryptionMismatch`, `ArchiveKeyMismatch`, `ArchiveVersionUnsupported`, `ArchiveStoreUnsupported`) | A site refused the archive's identity and uploads nothing; usually point PITR at a new prefix and take a full backup | [Archive identity](/docs/backup-and-restore/backup-restore#archive-identity) |
| `PITRArchiveUnsafeHistoryDetected` | A site set its permanent history-integrity marker after an out-of-band change; undo it, new prefix plus full backup. The marker removes every restore target that needs that site's bytes, including earlier ones | [Unsafe history marker](/docs/backup-and-restore/pitr-history-repair#unsafe-history-marker) |
| `PITRMysqlConfRefused` | The operator left a PITR-unsafe `spec.mysqlConf` option (filter, `binlog_format`, `binlog_row_image`) out of my.cnf; `PITRMysqlConfAccepted=False` names it. Remove the key, or disable PITR if the setting is required | [Operator-owned MySQL settings](/docs/configuration/configuration#operator-owned-mysql-settings) |
| `PITRArchiveReissueRiskDetected` | A site with divergent or quarantined archive rows was promoted; if it was recloned after a lossy failover, start a new prefix and take a full backup | [Reissue risk after a reclone](/docs/backup-and-restore/pitr-history-repair#reissue-risk-after-a-reclone) |
| `PITRDivergentHistoryExcluded` | A restore or verification excluded transactions outside the target history; confirm the excluded set is the lost, errant or other-branch history you meant to drop | [Target history and excludeGtids](/docs/backup-and-restore/backup-restore#target-history-and-excludegtids) |
| `PITROnHistoryTransactionsExcluded` | An excluded transaction on the target history precedes replayed ones; the result is not certified for it, so check the affected rows | [On-history exclusions](/docs/backup-and-restore/backup-restore#on-history-exclusions) |
| `PointInTimePartial` | `allowPartial` restored to the archive head instead of the requested target; confirm the earlier point meets the recovery objective | [Partial outcomes](/docs/backup-and-restore/backup-restore#partial-outcomes) |
| PITR restore or verification refused (`status.restore.reason` or the `Verified` reason is a `PITR*` token) | Read the token and its message: identity, dump, frontier, divergent history, gap, order or replay | [Restore refusals](/docs/backup-and-restore/backup-restore#restore-refusals) |
| `PITRArchiveRefused` (`MysqlStandbyCluster`) | The DR standby refused the source archive; the dump is published without a PITR window | [Restoring from a replicated archive](/docs/architecture/multi-cluster-dr#restoring-from-a-replicated-archive) |
| DNS update created/failed | Write `DNSEndpoint` for external-dns | [DNS failover stuck](/docs/operations/runbooks#dns-failover-stuck) |
| Split-brain or recovery pending | Fence losers or wait for manual recovery | [Split-brain recovery](/docs/operations/runbooks#split-brain-recovery) |
| Dragonfly promotion/sync/upgrade events | Preserve or restore cache/session continuity while MySQL remains authoritative | [Dragonfly degraded](/docs/operations/runbooks#dragonfly-degraded) |
| `KeyringPhase` / `KeyringUnsealed` | Informational — a site is moving through the keyring lifecycle | [Data-at-rest encryption](/docs/configuration/encryption-at-rest#how-the-keyring-lifecycle-works) |
| `KeyringEscrowMissing` / `KeyringEscrowCorrupt` | **Urgent.** A sealed site's only copy of its keys is gone or altered; do not restart that pod | [Data-at-rest encryption](/docs/configuration/encryption-at-rest#disaster-recovery) |
| `KeyringNotReadOnly` / `KeyringDigestMismatch` | Investigate the rendering — the site is not actually protected | [Data-at-rest encryption](/docs/configuration/encryption-at-rest#status-and-monitoring) |
| `KeyringRotationRefused` / `EncryptionAdoptionRefused` | Follow the supported rotation or adoption procedure | [Data-at-rest encryption](/docs/configuration/encryption-at-rest#rotating-keys) |
| `KeyringPromotionSkipped` / `KeyringPromotionRefused` | A rotating site is not a promotion target. If the group has no primary, finish the rotation (there is no cancel); then failover proceeds on the next poll | [Data-at-rest encryption](/docs/configuration/encryption-at-rest#rotating-keys) |
| `LicenseInvalid` | None required for availability. Check the token string and `kid`. Operator behavior is unchanged. | [Licensing](/docs/licensing) |
| `LicenseVerified` | Informational | [Licensing](/docs/licensing) |

## Minimum alert annotations

Each alert should include:

- `summary` with the failing group and namespace.
- `description` with immediate user impact.
- `runbook_url` pointing to this docs site.
- `dashboard_url` pointing to the relevant Grafana dashboard.

If an alert intentionally has no runbook or dashboard link, the change must include a specific operational rationale in the pull request. Do not use a bare `N/A`.
